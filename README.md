# Store Test Plugin

Harmless test plugin with a tiny canvas game (plugin webview demo). No secrets.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`store-test`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/store-test-1.0.5.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
